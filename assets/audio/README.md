# Optional sound / Optionaler Ton

**English:** Add your own recording as `NotifySound.mp3`, then set `audio.file` in your local configuration to `assets/audio/NotifySound.mp3` if that configuration is in the repository root. No recording is currently included. The example configurations use the system sound and work without this file. Audio files in this folder are ignored by Git; only add a distributable recording deliberately with its origin and license documented.

**Deutsch:** Lege deinen eigenen Ton als `NotifySound.mp3` hier ab. Liegt deine lokale Konfiguration im Projektstamm, setze darin `audio.file` auf `assets/audio/NotifySound.mp3`. Aktuell ist keine Aufnahme enthalten. Die Beispielkonfigurationen verwenden den Systemton und funktionieren ohne diese Datei. Git ignoriert Audiodateien in diesem Ordner; eine zur Weitergabe bestimmte Aufnahme bitte bewusst mit dokumentierter Herkunft und Lizenz hinzufügen.
